# Site Survey

Pre-job site survey for HVLS fan installs. Captures job info, each fan's location, mounting, power, controls, fire alarm, aerial equipment and a photo checklist. Prints or exports a summary.

**Open it:** https://thefanguys.github.io/Site-Survey/

Auto-saves on your phone as you type, so a reload won't lose your work. Tap the + button at the top to start a new survey (this clears the current one).

Single-file app (index.html), no build step. Hosted on GitHub Pages. Upload a new index.html to update it.
